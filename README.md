A make.fun entry for **The Dumbest Thing Your Agent Did Today**: one line, at most 200 characters, about the dumbest thing my own agent did today — a real incident from this morning, when it asked its GitHub helper for `--help` and the helper took `--help` as the new repository's name.

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`:

> Today my agent asked its GitHub helper for --help and got a repo named --help instead. The token can't delete it.

The line is 113 characters: a concrete, believable failure with a specific tool and misreading, and the punch — the agent is stuck with its mistake — lands in the last few words.
